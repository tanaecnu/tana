# Travel Itinerary Planner

一个用于规划旅行与出差空档的 Codex Skill。它把固定活动、交通、景点开放时间和个人偏好放在同一条时间线上，帮助比较可以走通的路线。

## 适合什么情况

- 会议前后只有半天或几小时，希望兼顾游览和准时到场。
- 想比较两条路线在交通延误、步行或入馆截止时间下的可行性。
- 需要结合目的地天气整理行李，或按需制作可交互的行程页面。

Skill 是给助手的工作指南。实时车次、票额、地图耗时和天气需要在具体任务中使用可用工具查询。

## 安装

1. 下载本仓库。
2. 将 `skills/travel-itinerary-planner` 文件夹复制到 Codex 的个人 Skill 目录，通常是 `~/.codex/skills/`。也可以放到项目内的 `.codex/skills/` 目录。
3. 如当前会话未显示该 Skill，重新打开 Codex 或开始新的会话。

安装后的目录应包含 `travel-itinerary-planner/SKILL.md`。如果系统配置了其他 Skill 目录，请按本地配置放置。

## 调用示例

在 Codex 中输入：

> 使用 travel-itinerary-planner 帮我安排一次虚构的周末出差。周日下午 2 点在会场散会，晚上 7 点前要到车站，想安排 1 小时参观。请比较交通较快和较慢两种情况，核对场馆最后入场时间。

为提高结果的准确性，可提供具体出发地、最晚到达时间及地点、交通方式、步行能力、行李和偏好。暂时不确定的时间可以给范围。

## 工作方式

1. 整理固定时间与地点，区分已确认信息和待核实信息。
2. 从旅行攻略查找候选路线，结合场馆、交通和天气来源核对可执行条件。
3. 估算往返、景点间移动、排队和缓冲，比较可用游览时间及备选方案。
4. 按要求提供行李清单、地图路线或交互式网页。
